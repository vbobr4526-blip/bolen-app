# Плагины для TikTokMod (TikTokModCloud)

Плагины в формате `.mtp` (API плагинов мода, `min_api` 3).

## «Экранное время» — `screen-time/bolen.screentime.mtp`

- Считает, сколько времени ты сегодня провёл в TikTok (счётчик сбрасывается в полночь).
- Каждые N минут **непрерывного** листания показывает окно «Пора сделать перерыв».
  Если выйти из TikTok больше чем на 5 минут, отсчёт начинается заново.
- В настройках мода, под заголовком плагина, две строки:
  - **Сегодня в TikTok**: окно со временем за сегодня и за текущую сессию;
  - **Напоминать о перерыве**: каждое нажатие переключает интервал
    10 → 20 → 30 → 45 → 60 мин → выключено (по умолчанию 20).

Плагин ничего не отправляет в сеть и не трогает аккаунт: он только считает время
и хранит его в своих настройках.

### Установка

1. Скачай `screen-time/bolen.screentime.mtp` на телефон.
2. TikTok → Настройки и конфиденциальность → первая строка (мод) → Плагины →
   Установить плагин → выбери файл.
3. Включи переключатель у плагина.

## «📊 Аналитик» — `analyst/bolen.analyst.mtp`

Круглая кнопка 📊 поверх видео, которая появляется **только на твоих роликах**.

- **Свой аккаунт** задаётся один раз: в настройках мода → «Мой аккаунт» (ввести @username)
  или долгим нажатием на 📊 на своём ролике. Пока аккаунт не задан, кнопка видна на всех роликах.
- **Кнопку можно перетащить** пальцем в любое место экрана — позиция запоминается.
- **Нажатие** показывает статистику именно того ролика, который сейчас на экране:
  просмотры и скорость набора, лайки/комментарии/репосты/сохранения в %, сравнение с лентой,
  грубый прогноз (через сутки и всего) и «Что исправить в следующем ролике».
  Если открыть тот же ролик снова через 20+ минут, прогноз строится по реальному росту.

Как плагин понимает, какой ролик на экране: он запоминает ролики из `onFeed` и раз в 0,8 с
ищет среди видимых на экране `TextView` описание одного из них. Соседние ролики, которые
TikTok держит заранее, находятся за краем экрана и не совпадают. Поэтому у ролика должно быть
описание (хотя бы хэштеги). Поля ролика читаются по ключам JSON из `@SerializedName`, так что
обфускация TikTok не мешает. В журнал мода пишутся строки `[analyst] feed: …`,
`[analyst] screen: …` и `[analyst] own video seen: …` — по ним видно, доходят ли до плагина
твои ролики.

## Сборка из исходников

```
./build.sh screen-time
./build.sh analyst
```

Нужны JDK и Python 3. `android.jar` и `dx` скачиваются с Maven Central в `tools/`.
Класс `Plugin` из `api-stub/` — заглушка только для компиляции, в `.mtp` он не попадает.
Методы `host()` (PluginContext) вызываются через рефлексию, поэтому заглушка
PluginContext не нужна.
